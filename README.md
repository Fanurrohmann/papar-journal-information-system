# PAPAR Journal Information System

Website informasi Jurnal PAPAR Jawa Timur yang dikembangkan untuk menyediakan akses informasi jurnal secara online. Proyek ini dikerjakan secara tim dengan fokus pada penyajian informasi yang mudah diakses, tampilan yang responsif, dan pengalaman pengguna yang sederhana.

## Deskripsi Proyek

PAPAR Journal Information System merupakan website yang digunakan untuk menampilkan informasi jurnal dan publikasi secara online. Website dirancang agar pengguna dapat mengakses informasi dengan mudah melalui berbagai perangkat.

## Peran Saya

Pada proyek ini saya berkontribusi sebagai:

* UI/UX Designer
* Web Developer

Tanggung jawab yang saya kerjakan meliputi:

* Merancang antarmuka pengguna (UI) website.
* Membantu menyusun alur penggunaan (user flow) dan pengalaman pengguna (UX).
* Mengimplementasikan desain ke dalam website.
* Membantu pengembangan fitur website.
* Melakukan deployment website ke hosting.
* Melakukan pengujian sistem sebelum dipublikasikan.

## Teknologi yang Digunakan

## Fitur

* Halaman informasi jurnal.
* Tampilan responsif untuk desktop dan mobile.
* Manajemen konten informasi.
* Navigasi yang sederhana dan mudah digunakan.
* Sistem publikasi informasi berbasis web.
